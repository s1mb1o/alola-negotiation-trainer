# Benchmark guide

Read [`../CLAUDE.md`](../CLAUDE.md) and [`../AGENTS.md`](../AGENTS.md) first.

- Create a fresh session for each independent trial.
- Disable hints and use `normal` difficulty.
- Run each tested model in both roles.
- Record provider, model, role, prompt version, seed, scenario, and language.
- Do not write participant credentials or provider credentials to artifacts.
- Treat provider failures and incomplete sessions as explicit results.
